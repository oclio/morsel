> **ArrayMergeStrategy** = `"replace"` \| `"concat"`

Defined in: [packages/core/src/merge/deep-merge.ts:10](https://github.com/oclio/morsel/blob/8fd7afe9ac0aab0d79829dd6a93f11cf6772962a/packages/core/src/merge/deep-merge.ts#L10)

Array merge strategy for `deepMerge`.

- `'replace'` (default): the override array replaces the base array.
- `'concat'`: the override array is concatenated to the base array.
